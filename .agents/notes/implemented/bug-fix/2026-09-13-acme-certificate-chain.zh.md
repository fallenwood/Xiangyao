# Agent Note: ACME 证书链保留

Status: implemented

[English](2026-09-13-acme-certificate-chain.md) | 中文

## Problem

当 ACME 服务器返回证书包时，Xiangyao 之前只将生成的 PFX 中的第一张证书保存下来。中间证书被丢弃，导致 PKCS#12 归档中缺少浏览器和 TLS 客户端正确校验证书所需的完整链。

## Decision

ACME 证书转换现在会把 PEM 包中返回的每一张证书都写入 PKCS#12 存储，并将私钥附加到整条证书链上。叶子证书和所有中间证书会保存在同一个归档中，密钥条目仍会关联完整链，因此客户端可以直接从导出的 PFX 构建信任路径。

## Alternatives considered

- 仅保留叶子证书：修改最小，但会导致浏览器和 TLS 客户端无法完成证书链校验。
- 将证书链拆分到不同文件并要求外部编排：保留了签发链，但增加了运维复杂度和配置漂移。
- 再次只导出第一张证书：没有修复根因，链问题仍然存在。

## Consequences

- TLS 客户端可以根据 PFX 中完整的签发链完成证书验证。
- 续期后的证书无需手动重建证书链即可直接使用。
- 导出的归档体积会略大一些，但它准确反映了 ACME 证书机构返回的完整证书包。
